# C-Direct — Brand Kit (checkmark mark)

The mark: the hyphen in **C-Direct** is an amber checkmark, set in Anton.
Colours: forest green `#0D2B24` · amber `#C98A2B` · off-white `#FAFAF7`.

## Rules
- Amber is for the check and large display type only — never body text (fails contrast).
- Don't recolour, stretch, add effects, or re-typeset the wordmark.
- Before trademark filing or large-format print, have a graphist do a fine pass on the
  check's angle/weight against the letterforms. Web/app/document ready as-is.
